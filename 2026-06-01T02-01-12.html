구글 제미나이(Gemini) 무료 API 키 발급 및 실시간 검증 가이드

1단계 구글 무료 API 키 발급받기

  1. Google AI Studio 접속:
    https://aistudio.google.com/ 링크로 접속합니다.
  2. 구글 계정 로그인:
    소유하고 계신 일반 개인 Gmail 계정으로 로그인하시면 즉시 무료 혜택(Free Tier)이 주어집니다.
  3. API Key 생성하기:
    좌측 상단의 파란색 [Get API key] 버튼을 누른 뒤, [Create API key in new project]를 선택해 새로운 키를 발급받습니다.
  4. 키 복사:
    AIzaSy로 시작하는 생성된 API 키 스트링을 안전한 곳에 복사해 둡니다.

실시간 검증 이 페이지에서 즉시 내 키 테스트해보기

발급받으신 API 키를 아래에 입력하고 검증 버튼을 눌러보세요. 이 페이지는 사용자의 어떠한 데이터나 API 키도 서버로 전송 또는 저장하지 않고 웹 브라우저 로컬에서만 실행됩니다.

API 키와 모델을 선택한 후 테스트 버튼을 눌러보세요.

2단계 내 컴퓨터용 전체 테스트 파일 소스코드

따로 편집기(VSCode 등)를 쓸 필요 없이 메모장에 아래 코드를 그대로 붙여넣고 test.html로 저장해 실행해 볼 수 있는 화면 입력창 탑재 버전 코드입니다. 

<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Gemini API Tester</title>
</head>
<body style="background-color: #0b0f19; color: #f1f5f9; font-family: sans-serif; padding: 25px;">
    <h2>CoachMe AI - 로컬 테스터</h2>
    <div style="margin-bottom: 15px;">
        <label style="display:block; margin-bottom:5px;">제미나이 API Key 입력:</label>
        <input type="text" id="apiKeyInput" placeholder="AIzaSy..." style="width: 100%; max-width: 400px; padding: 10px; border-radius: 5px; border: 1px solid #334155; background: #0f172a; color:#fff;">
    </div>
    <button onclick="analyzeWorkout()" style="background: linear-gradient(90deg, #6366f1, #a855f7); color: white; border: none; padding: 12px 20px; font-weight: bold; border-radius: 6px; cursor: pointer;">
        AI 분석 및 점진적 과부하 연산 시작
    </button>
    <pre id="outputBox" style="background:#0f172a; border: 1px solid #1e293b; color: #cbd5e1; padding: 15px; margin-top:15px; border-radius: 6px; white-space: pre-wrap; line-height: 1.6;">[여기에 분석 결과가 표시됩니다]</pre>

    <script>
        async function analyzeWorkout() {
            const key = document.getElementById("apiKeyInput").value.trim();
            const output = document.getElementById("outputBox");
            if(!key) {
                output.innerText = "에러: API 키를 먼저 입력해 주세요!";
                return;
            }
            output.innerText = "제미나이 AI가 데이터를 읽고 분석을 진행 중입니다...";
            const url = `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=${key}`;
            const body = {
                contents: [{
                    parts: [{
                        text: "너는 점진적 과부하 원칙을 철저히 지키는 헬스 전문 트레이너야. 아래 유저의 벤치프레스 3주 치 세션 로그를 분석해서 다음 훈련 세션 때 증량해야 할지, 혹은 횟수를 올려야 할지 딱 2문장 내외로 명확히 코칭 가이드를 제공해줘.\n\n- 1주 전: 80kg x 6회 (3세트)\n- 어제: 80kg x 8회 (3세트)"
                    }]
                }]
            };
            try {
                const res = await fetch(url, {
                    method: "POST",
                    headers: { "Content-Type": "application/json" },
                    body: JSON.stringify(body)
                });
                const data = await res.json();
                if(data.error) {
                    output.innerText = "오류 반환: " + data.error.message;
                } else {
                    output.innerText = data.candidates[0].content.parts[0].text;
                }
            } catch(e) {
                output.innerText = "네트워크 에러 발생: " + e.message;
            }
        }
    </script>
</body>
</html>

3단계 무료 사용 규칙 및 라이브 배포 보안 경고

  • 무료 티어 호출 한도: 분당 최대 15회(15 RPM), 일일 최대 1,500회(1,500 RPD)까지 요금이 청구되지 않고 완벽하게 무료입니다.
  • 사용자 보안 경고: 유저 개인 로컬 디바이스 혹은 로컬 `html` 파일 실행 시에는 코드 안에 API 키를 기재해도 유출 위험이 없습니다.
⚠️ 안티그라피티 개발팀 참고 스펙:
추후 Vercel, Netlify 등으로 서비스를 정식 배포할 때는 웹사이트의 [개발자 도구 -> 소스 코드 보기]를 통해 사용자의 API 키가 무단 유출될 수 있습니다. 따라서 백엔드 환경변수(ENV) 파일이나 프록시(Proxy Server) 단일 라우터를 거쳐 호출할 수 있도록 프론트엔드-백엔드 보안 아키텍처 적용을 권장합니다.
